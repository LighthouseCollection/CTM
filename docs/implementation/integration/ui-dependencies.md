# UI dependencies and ownership

These are contract/acceptance dependencies identified during the full45-screen UI reconciliation, not requests to change approved schema to match a UI shortcut. UI is not claiming them completed. Backend ownership is [issue2](https://github.com/LighthouseCollection/CTM/issues/2), applicant [issue1](https://github.com/LighthouseCollection/CTM/issues/1), council [issue3](https://github.com/LighthouseCollection/CTM/issues/3), independent report QA [issue15](https://github.com/LighthouseCollection/CTM/issues/15). Shared integration is [issue4](https://github.com/LighthouseCollection/CTM/issues/4).

| ID | Exact dependency / current source evidence | Owner / next deliverable |
|---|---|---|
| AUTH | Genuine provider/session acceptance; current sign-in must use configured Microsoft/Google/Apple, never old prototype passwords. | Backend/operator: provider credentials and actual login acceptance, separate from UI rendering. |
| APPLICANT | Latest repeat/conditional/validation/history modules are delivered on applicant branch, not incorporated into this UI base104e4fd. | Applicant/governance: integrate named current modules (issue1 reports1d20bfa), preserving all shared hooks; rerun exact successor.
