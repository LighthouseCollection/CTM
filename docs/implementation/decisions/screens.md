# Screen decisions register

One accepted decision per screen element. Builders and the UI finish gate treat
these as locked; changing one needs a new dated owner decision (add a new row
and mark the old one superseded). Only explicit owner decisions go here, not
discussions or proposals. Maintained by `ctm-spec-analyst`; pruned/audited by
`ctm-drift-auditor`.
