# Claude: council workspace

Implement council workflows in LighthouseCollection/CTM on branch
work/claude-council, in your own clone. Read governance.md and approved build-spec
contracts first. Own council frontend modules/tests; shared backend/migrations
belong to VM-FRM. Coordinate shared shell/app.js hooks through governance.

Prioritize completeness review/return, session agenda/attendance/assignment,
case-manager reports and communications, hearings/decision type and grounds,
votes/presidential approval, signed decree PDF/issue/close/explicit release.
Follow confirmed role permissions; case manager does not manage decrees. Existing
signed records/history must remain preserved. Use the accepted question bank
exactly. Use Plenix CDN0.58.0, English/Arabic and RTL, plus documented split views.

OCR/audio are low priority; honest placeholders are acceptable. Request missing
APIs on the stream issue, rather than embedding mocks. Push a draft PR early and
report checks, blockers and remaining work. Do not merge, deploy or edit protected
architecture files independently.
