## Examples worth refining

- PRS-01: a neutral existence question is better than assuming a pressure/threat existed.
- ADD-02: accept unknown onset and ask discovery separately rather than conflating the dates.
- CHD-03: distinguish a genuine change of expectation from learning later about an earlier position. Explain this in two short questions rather than one abstract sentence.
- SEP-02: establish whether living together actually resumed before asking why it resumed.
- WED-03: preserve original evidence-support coverage when introducing words/actions at the time; do not lose existing information in simplification.
- EVD-02: ask about extracts/translations/versions only where it matters and is not already clear from the file record; no technical authentication requirement.
- MED: explicitly include evaluation as well as treatment, but make the primary wording shorter. Separate the subject's own experience from knowledge about the spouse. A statement about the spouse is not a signed authorization for the spouse's records.

## Simplified interview delivery

Keep the current 19-family library for reuse and coverage. It includes shared timeline/evidence functions and a pending medical-wording family; it is not a nineteen-part compulsory interview. A normal family can present a small number of primary prompts, with existing detailed questions/probes available only when unanswered facts warrant them. Do not impose a fixed quota or delete source questions to reach one.

Suggested plain Infidelity wording for review, mapped to existing IDs:

| Existing home | Primary question | Optional detail only when missing |
|---|---|---|
| INF-01 | What happened that led you to raise a concern about an affair? | Specific event or communication if the account gives only a label. |
| INF-02 / TIM | When do you say it happened, and when did you learn about it? | Exact/approximate/unknown date, and what supports the sequence. Deliver as two questions if needed. |
| INF-03 | What did you personally see or hear? | Other sources and what remains uncertain. |
| INF-04 / EVD | Which submitted statement or evidence relates to that account? | Exact source/version and what it does or does not support, if unclear. |

These are candidate wording refinements, not adopted changes. Existing submitted evidence appears as context rather than being requested/uploaded again. Original narrative, audio and transcript remain distinct. No forced admission/denial workflow or cross-applicant disclosure is introduced.

Children example: "What did you discuss about having children before marriage?" Then only if relevant: "What was agreed?" and "Did that change later, or did you learn something different later?" Reuse dates/evidence already supplied.

Money example: "What financial fact or disagreement is relevant to your request?" Clarify only the important undisclosed statement, event, date or evidence that remains missing. No broad financial audit.

Medical example: "Have you had a medical, psychological or psychiatric evaluation or treatment relevant to this issue?" Ask known spouse-related facts separately where relevant; preserve Unknown, signed-release scope and source attribution. Exact institutional wording still requires agreement.
