# Guided applicant interview — category-based template

User-confirmed structure: the assigned council member selects Common question family categories, works through detailed numbered prompts and assembles the report under those selected category headings. This is an interview and factual-discovery workflow, separate from the concise applicant application and rare council-session testimony.

The [category bank](CTM-interview-category-bank.md) contains the concrete expanded English review prompts and stable codes. The [interactive category planner](reference-study/interview-category-planner.html) shows how selection changes the report outline. The [reference-review decision register](CTM-reference-review-decisions.md) records every accepted/rejected/clarified source proposal. Expanded wording is a review draft, not a published institutional version; approved bilingual versioning remains required.

## Retained common structure

1. Identity and recording opening for every interview/new recording.
2. Requested outcome, factual basis and relevant application clarification.
3. Selected detailed categories with actual answers, dates/source certainty and evidence references.
4. Closing clarification.
5. Separate interviewer observations/recommendations; original audio and reviewed transcript references remain separate.

## Selectable common question families

Decision to marry; Children; Money; Intimacy; pressure/threats; doubts before marriage; wedding circumstances; misrepresentation/concealment; infidelity; desertion/abandonment; abuse; leaving/changing faith; addiction; relevant personal/family background; when problems began; separation history; reconciliation efforts; evidence/factual clarification. A medical/psychological help category has more explicit draft wording awaiting confirmation.

Each selected category exposes detailed questions. Selection is relevance-based, not a requirement to interrogate every category or adopt a new ground. No generic communication category, civil/church supplement, full prior-marriage interview supplement or separate appeal question block is included after the user's rejections. Existing appeal/application processes remain intact.

## Source and record separation

Preserve template/category/question versions and actual selected order. Removing a category later never silently deletes prior answers/history. New case-specific questions remain attributable. Manual answers are not generated from transcript; report assembly organizes the stored answers rather than creating findings through AI. Evidence links retain exact versions. All prior author/assignment/council-only/closed-proceeding restrictions remain.

The free-form [priest testimony template](CTM-priest-testimony-template-draft.md) is a separate link-based report identifying the marriage and subject party, not a priest being interviewed through this bank.

Earlier flat bilingual draft revision 2 is retained in archive/CTM-guided-interview-template-draft-v2-before-category-review.md for wording provenance. It is not the current selection model.

## Investigation hierarchy, source context and evaluation releases

User refinement: organize by petition nature and template, reusing Common question families across templates. Council can switch views without changing answers. Application marriage dates and submitted evidence/statements are exact versioned source context for confirmation and factual inquiry within the questionnaire. See CTM-investigation-model.md; no automatic answer copying or other-party disclosure. Medical/psychiatric testing/release records are separately confirmed, while exact medical interview wording remains pending. Research prompts are in CTM-category-research-prompts.md.



## Adopted contextual questioning — 2026-10-20

The user accepted the complete [Context-Sensitive Investigative Questions companion](CTM-context-sensitive-investigative-questions.md) for the question bank, intake-template preparation and reporting workflow. This supersedes the earlier presentation rule that every optional probe must be folded into the main question. The 59 existing main questions and agreed category names remain unchanged. The companion headings do not rename or split those categories. No retired question is reactivated; no removed standalone EVD section is restored. References to EVD mean existing evidence/file-version links, not a new EVD questionnaire.

The assigned case manager priest chooses Topic group → Question categories → Questions, with the current foundational questions retained, and can add case-specific questions. Each stable question ID has versioned conditional prompts, a trigger and avoid/reuse guidance. Ask only for missing relevant facts after checking the application, earlier responses, chronology and authorized evidence. Prompts are optional, not required fields or proof thresholds; no automatic branching or automatic inference is adopted. A completed response is referenced rather than collected again. Keep each party's account and evidence permissions separate.

Template preparation and council interviewing can use these prompts as interviewer aids. They are not automatically inserted as extra applicant questions; the case manager may explicitly select or adapt a relevant clarification before sending. The exact sent questions and their order are preserved; the recipient's submitted response remains locked as already agreed. Sending freezes questions, not a copy of all guidance. Follow-up investigations create separate linked intakes/reports. Main wording changes still require an explicit decision; acceptance of the companion does not apply the separate seven-revision review.

Interviewer-only avoid/reuse instructions and the separate council assessment guide remain guidance, not answers, applicant-facing report content or automatic findings. The original main question, optional prompt definition/version and any clarification actually asked must be distinguishable. Human council findings remain separate from attributed answers, source evidence, transcript and priest testimony. No credibility scoring or canonical decision automation is introduced.

Medical signed-release, restricted disclosure and local document processing rules continue. Audio transcription authorization does not authorize external medical-document AI processing. No extra mandatory uploads, child interviews, general witness module or broad medical-history collection is added.

The planner now shows available prompts in collapsed **Conditional follow-up prompts** under the corresponding questions, with no empty helper section. This is a planning artifact only. Full trigger/avoid-reuse guidance and council assessment text remain available in the adopted companion.
